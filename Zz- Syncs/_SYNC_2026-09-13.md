## Methodology note

An initial pass resolved each row's "Maps to" controller/action to its *whole*
view directory (e.g. `app/views/orders/**`) and flagged 43 rows as drifted.
Almost all of those were false positives: several guides share one large
controller (`OrdersController`, `TimesheetsController`, `RatesController`,
`ProductAllocationsController`) whose *other*, unrelated actions/tabs had
changed. Re-resolved every flagged row to its specific action's view file(s)
(e.g. `app/views/orders/tabs/products.html.erb`, not all of `orders/tabs/*`)
and re-diffed — this cut 43 candidates down to 2 genuine, unaddressed drifts.
The other 41 were either (a) changes to sibling actions the row doesn't cover,
or (b) changes already reflected in the guide's own content/Notes despite a
stale `Release`/`Version` cell (see "Stale Release cells" below) — cross-checked
against actual guide text and `_VERIFICATION.md` Notes in each case, not just
the diff in isolation.
