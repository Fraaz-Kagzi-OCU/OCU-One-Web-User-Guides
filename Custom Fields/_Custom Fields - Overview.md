# Custom Fields — Overview

**Custom fields** are extra, organisation-specific sections that can appear on a record's overview page alongside its standard fields — for example a "Site Info" section on a Job. Not every record has one; it depends on what's been set up for that record type. They work the same way wherever they appear — jobs, projects, tickets, and other record types. See [Filling in and editing custom field values on a record](Filling%20in%20and%20editing%20custom%20field%20values%20on%20a%20record.md) for how to fill one in and edit it later.
