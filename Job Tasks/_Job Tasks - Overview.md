# Job Tasks — Overview

A **Job Task** is a piece of work tracked inside a job, distinct from the job itself — a job is broken into one or more tasks (set up automatically from its job type when the job is created), each with its own type, priority, status, RAG tracking, todos, and — for some task types — linked records. This is distinct from the [Tasks](../Tasks/_Tasks%20-%20Overview.md) landing page, which lists project-linked tasks across the whole organisation.
