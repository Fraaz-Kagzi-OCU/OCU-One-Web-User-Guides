# Settings — Overview

**Settings** is where an admin manages every piece of reference data your organisation uses — from asset and job types to rate books, labels, and automation rules. Start with [Finding your way around Settings (landing page)](Finding%20your%20way%20around%20Settings%20%28landing%20page%29.md) to see how it's organised, then:

- [Configuring label groups](Configuring%20label%20groups.md) — colour-coded tags for records, grouped for organisation
- [Managing folder sets (document folder templates)](Managing%20folder%20sets%20%28document%20folder%20templates%29.md) — reusable document folder structures
- [Building a notification journey](Building%20a%20notification%20journey.md) — scheduled sequences of notifications sent to a group over time

This folder will keep growing as more of the many other Settings sub-areas (asset/job/project types, pipelines, rate configuration, roles & permissions, and more) get written up.
