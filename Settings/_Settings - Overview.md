# Settings — Overview

**Settings** is where an admin manages every piece of reference data your organisation uses — from asset and job types to rate books, labels, and automation rules. Start with [Finding your way around Settings (landing page)](Finding%20your%20way%20around%20Settings%20%28landing%20page%29.md) to see how it's organised, then:

- [Configuring label groups](Configuring%20label%20groups.md) — colour-coded tags for records, grouped for organisation
- [Managing folder sets (document folder templates)](Managing%20folder%20sets%20%28document%20folder%20templates%29.md) — reusable document folder structures
- [Building a pipeline with stages](Pipelines%20%26%20Stages/Building%20a%20pipeline%20with%20stages.md) — the sequence of stages a record moves through, with ageing thresholds
- [Attaching a pipeline to a type](Pipelines%20%26%20Stages/Attaching%20a%20pipeline%20to%20a%20type.md) — making a pipeline apply to real Assets, Issues, Projects, Records, Tickets, or Users
- [Building a notification journey](Building%20a%20notification%20journey.md) — scheduled sequences of notifications sent to a group over time
- [Configuring Hub survey types](Hub%20Administration/Configuring%20Hub%20survey%20types.md) — survey types used when creating Hub surveys
- [Configuring app-launcher shortcuts](Hub%20Administration/Configuring%20app-launcher%20shortcuts.md) — shortcuts to other tools shown in the App Launcher menu
- [Creating a shared visit plan and its recurring visit schedules](Visit%20Scheduling/Creating%20a%20shared%20visit%20plan%20and%20its%20recurring%20visit%20schedules.md) — reusable recurring maintenance schedules that can be attached to any asset
- [Attaching a custom (asset-specific) visit plan](Visit%20Scheduling/Attaching%20a%20custom%20%28asset-specific%29%20visit%20plan.md) — a one-off visit plan scoped to a single asset
- [Creating and managing rotating shift patterns](Scheduling%20Reference%20Data/Creating%20and%20managing%20rotating%20shift%20patterns.md) — rotating work schedules built from shifts on a repeating cycle
- [Managing availability types](Scheduling%20Reference%20Data/Managing%20availability%20types.md) — categories used to record why someone isn't (or is extra) available for work
- [Setting up tag types and tags](Tags%20%26%20Notifications/Setting%20up%20tag%20types%20and%20tags.md) — reusable tags, grouped by type, that can be applied to users and records
- [Setting up notification groups and recipients](Tags%20%26%20Notifications/Setting%20up%20notification%20groups%20and%20recipients.md) — named groups of people, built from tags and/or named users, who all receive the same notifications
- [Building a field set with field groups and field types](Workspace%20Builder/Building%20a%20field%20set%20with%20field%20groups%20and%20field%20types.md) — reusable custom fields, organised into groups, that attach to jobs, assets, and other objects
- [Configuring a check-type field's pass/fail (RAG) scoring](Workspace%20Builder/Configuring%20a%20check-type%20field%27s%20pass-fail%20%28RAG%29%20scoring.md) — positive/resolved/negative outcomes with their own RAG colours and optional auto-created records
- [Configuring records-type field columns and auto-titles](Workspace%20Builder/Configuring%20records-type%20field%20columns%20and%20auto-titles.md) — display columns and default naming for records embedded inside a field
- [Attaching a field set to a type](Workspace%20Builder/Attaching%20a%20field%20set%20to%20a%20type.md) — making a field set's fields actually appear on real records
- [Building a custom form](Workspace%20Builder/Building%20a%20custom%20form.md) — multi-page field-driven questionnaires used out in the field
- [Adding elements to a form page](Workspace%20Builder/Adding%20elements%20to%20a%20form%20page.md) — the full range of question and capture types a form page can hold
- [Managing job types and task types](Type%20Management/Managing%20job%20types%20and%20task%20types.md) — job categories with RAG scoring, built from a shared list of reusable task types
- [Building job task pipelines and sub-statuses](Type%20Management/Building%20job%20task%20pipelines%20and%20sub-statuses.md) — the ordered sequence tasks move through, and finer-detail sub-statuses under any job status
- [Configuring project types, record types, and record groups](Type%20Management/Configuring%20project%20types%2C%20record%20types%2C%20and%20record%20groups.md) — public-creation settings on project/record types, and grouping record types together
- [Pinning related record types to a record type](Type%20Management/Pinning%20related%20record%20types%20to%20a%20record%20type.md) — flagging Project Types, Job Types, or other Record Types as related, with a quick-reference field selection

- [Managing todo types, event types, warning types, and lead sources](Type%20Management/Managing%20todo%20types%2C%20event%20types%2C%20warning%20types%2C%20and%20lead%20sources.md) — smaller categorisation screens for to-dos, calendar events, job warnings, and lead tracking
- [Building an automation rule](Automation/Building%20an%20automation%20rule.md) — triggers, conditions, and actions that automatically react to changes across the app

- [Common action types reference](Automation/Common%20action%20types%20reference.md) — every effect a rule can trigger

- [Creating permission sets (per-module grants and per-type overrides)](Access%20Control%20%28Roles%20%26%20Permissions%29/Creating%20permission%20sets%20%28per-module%20grants%20and%20per-type%20overrides%29.md) — module-wide grants with optional per-type fine-tuning
- [Creating roles and assigning permission sets](Access%20Control%20%28Roles%20%26%20Permissions%29/Creating%20roles%20and%20assigning%20permission%20sets.md) — bundling a permission set per module into one role people can be assigned
