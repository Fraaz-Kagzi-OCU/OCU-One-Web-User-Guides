# Managing availability types

**Availability Types** are the categories used to describe why someone isn't available for work — for example Holiday, Sick, or Training — as well as categories for extra availability like Overtime or Cover. This screen lives under **Settings > Availability Types**.

## The Availability Types list

The list shows every availability type with its **Availability Type** (whether it counts as **Available** or **Unavailable**), whether it's **Authorised** (needs approval before it applies), its **State**, and its **Access**.

![Availability Types list showing existing types such as Holiday, Sick, Cover, and Overtime](attachments/Managing%20availability%20types/01-availability-types-list.jpg)

You can filter the list by **Name** or **State**, or add more filters with **+ Filter**.

## Creating an availability type

1. Click **+ Availability Type**.
2. Fill in:
   - **Name** — for example **Annual Leave**.
   - **Description** — an optional longer explanation, hidden behind an **Add description** link until needed.
   - **Icon** and **Colour** — how the type is shown elsewhere in the app.
   - **Availability Type** — choose **Unavailable** (the person can't work) or **Available** (extra availability, like Overtime or Cover).
   - **Authorised?** — tick this if the type needs sign-off before it's approved.

   ![New Availability Type form filled in with name, description, and Authorised ticked](attachments/Managing%20availability%20types/02-new-availability-type-form.jpg)

3. Click **Create Availability Type**. It's added to the list:

   ![Availability Types list with "Annual Leave" now showing alongside the existing types](attachments/Managing%20availability%20types/03-availability-type-created.jpg)

## Editing an availability type

Click a type's name to reopen it in the same form, with its values filled in — change anything and click **Update Availability Type** to save, or **Never mind** to close without saving.

![Edit Availability Type form pre-filled with "Annual Leave"'s saved name, description, and settings](attachments/Managing%20availability%20types/04-edit-availability-type-form.jpg)

## Deactivating an availability type

Click the eye icon in a type's **State** column to deactivate it. You'll be asked to confirm:

![Confirm dialog asking "Are you sure you want to deactivate this?"](attachments/Managing%20availability%20types/05-deactivate-confirm.jpg)

Once deactivated, the type drops off the default list. Turning on **Include closed?** does not currently bring it back into the list — once deactivated, a type stops showing here regardless of that toggle.

![Availability Types list after deactivating "Annual Leave" — it no longer appears, and turning on "Include closed?" doesn't bring it back](attachments/Managing%20availability%20types/07-include-closed-still-missing.jpg)

## Things to know

- **Availability Type** controls whether the category counts as time someone is unavailable (like Sick or Holiday) or extra availability (like Overtime or Cover) — pick whichever matches how it should be treated.
- **Authorised?** marks a type as needing sign-off, but doesn't change anything about how it looks or behaves on this screen — it's a flag other parts of the app can use.
