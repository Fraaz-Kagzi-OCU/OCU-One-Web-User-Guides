# Editing or deleting an issue

Once an issue has been raised, you can update its details or remove it
entirely from its own overview page.

## Editing an issue

Open the issue and click **Edit**, next to the pipeline stage button in
the top-right.

![Issue overview page with the Edit button highlighted](attachments/editing-or-deleting-an-issue/01-issue-overview-with-edit.png)

This opens the same form used when the issue was created — title,
reference, and description can all be changed. The issue type and the
asset or visit it's raised against can't be changed here.

![Edit form with an updated description](attachments/editing-or-deleting-an-issue/02-edit-description.png)

Click **Update Issue** to save. The overview page reflects the change
immediately.

![Issue overview page showing the updated description](attachments/editing-or-deleting-an-issue/03-description-updated.png)

## Deleting an issue

Click the trash icon next to **Edit**.

![Duplicate issue's overview page with the trash icon highlighted](attachments/editing-or-deleting-an-issue/04-duplicate-issue-before-delete.png)

A confirmation dialog appears — click **Yes** to confirm, or **Cancel** to
back out.

![Confirm dialog: "Are you sure you want to delete this?"](attachments/editing-or-deleting-an-issue/05-delete-confirm-dialog.png)

Once confirmed, you're taken back to the Issues list and the deleted
issue no longer appears in it.

![Issues list after the duplicate issue was deleted, no longer showing it](attachments/editing-or-deleting-an-issue/06-issue-deleted.png)
