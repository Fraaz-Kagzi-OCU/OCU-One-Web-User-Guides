# Media & Attachments — Overview

**Media & Attachments** covers two small, unrelated pieces of behaviour that show up wherever photos and files can be attached to something in OCU One — a job, a project, a ticket, an estimate, and more. They don't form a sequence; each is its own self-contained action you might reach for at a different point.

## The two pieces

**Choosing which attachments appear on a PDF export** covers the screen that appears whenever you preview or download a PDF for a record with photos attached — a chance to pick exactly which images show up in that PDF, either as a permanent default or just for one export. See [Choosing which attachments appear on a PDF export](Choosing%20which%20attachments%20appear%20on%20a%20PDF%20export.md).

**Removing an uploaded file attachment** covers taking back a file you've just attached to a form — like an Estimate's Files field — before you've saved it, without having to start the whole form over. See [Removing an uploaded file attachment](Removing%20an%20uploaded%20file%20attachment.md).

## Why this matters

Both are small conveniences, but they matter for the same reason: attachments are easy to get wrong in the moment — the wrong photo included in a client-facing PDF, or the wrong file attached to a form — and neither should require redoing everything else around it. Choosing PDF visibility lets you control what a client or colleague actually sees without deleting or reorganising anything; removing a just-uploaded file lets you fix a mistake mid-form without losing the rest of what you've filled in.

Not every record type uses both of these — a record with no attachments at all won't show the PDF-selection screen, and a form without a Files field won't have anything to remove — but wherever attachments genuinely exist, this is how you manage what's shown and what's kept.
